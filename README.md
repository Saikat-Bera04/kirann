## 💻 Getting Started

To run this project locally, follow these steps:

### Prerequisites

Ensure you have [Node.js](https://nodejs.org/) (v20 or higher recommended) and `npm` installed.

### Installation

1.  Clone the repository:
    ```bash
    git clone https://github.com/Saikat-Bera04/kirann.git
    ```
2.  Navigate to the project directory:
    ```bash
    cd kirann
    ```
3.  Install dependencies:
    ```bash
    npm install
    ```

### Running the Development Server

Start the development server with Turbopack for faster builds:

```bash
npm run saikat
```

Alternatively, you can use the standard Next.js dev command if you prefer:
```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

## 📁 Project Structure

*   `src/app/`: Next.js App Router pages and layouts.
*   `src/components/`: Reusable React components.
*   `src/lib/`: Utility functions and static data (e.g., `data.ts` containing bio, skills, and project info).
*   `public/`: Static assets like images and graphics.
